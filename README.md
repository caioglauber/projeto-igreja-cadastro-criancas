# projeto-igreja-cadastro-criancas
Conectando Java com Banco de Dados MySQL

Esse projeto terá como objetivo colocar em prática todo o assunto estudado em java como List, Set, Map, conectividade com JDBC e interação com banco de dados MySQL em prática.  Espero aprimorar esse projeto a cada dia e quem sabe implementar na minha igreja como um sitema de cadastro e controle das criancas nos cultos de domingos.
